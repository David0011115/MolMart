# QR-каталог для холодильника магазина

Информационный сайт: покупатель сканирует QR-код и видит товары, составы, цены и метки. Корзины нет. Хостинг: GitHub Pages.

## Что где лежит

**Общий код (при запуске нового заказчика не трогаем):**
- `index.html` — дизайн и логика сайта
- `sw.js` — офлайн-режим
- `fonts/` — шрифты Onest (основной текст, есть казахские буквы) и Unbounded (логотип и цены) в формате WOFF2, урезаны до нужных букв. Лицензия OFL — `fonts/OFL-*.txt`, её файлы не удалять

**Файлы заказчика (меняем под каждого):**
- `config.js` — название магазина, адрес, часы, цвета, валюта, ссылка на таблицу цен, номер счётчика Метрики
- `products.js` — товары: названия, бренды, разделы, составы, перевод на казахский
- `img/` — фото товаров (WebP, 560×560)
- `prices.csv` — запасной файл цен (основные цены берутся из Google Таблицы). Обновляется сам раз в сутки в 05:17 по Алматы: `.github/workflows/update-prices.yml` + `tools/update_prices.py`. Если таблица недоступна или данных стало заметно меньше, файл не трогается и запуск помечается ошибкой. Ручной запуск: вкладка Actions → «Обновление запасных цен» → Run workflow
- `manifest.json`, `icon-*.png`, `apple-touch-icon.png` — название и иконки приложения

## Как добавить товар
1. Положить фото в `img/` (следующий номер, WebP).
2. Добавить товар в `products.js` с путём `image:"img/NN.webp"`.
3. Добавить строку с таким же названием в Google Таблицу (цены, метки, наличие).

## Цены
Цены, скидки, метки и наличие приходят из Google Таблицы автоматически (обновление в течение 5–10 минут). В `products.js` цены не хранятся.

## Описания товаров в таблице (лист «Товары»)

Вес, состав, КБЖУ, аллергены и казахский перевод можно вести в Google Таблице, лист «Товары» (колонки: Товар, Вес, Состав, КБЖУ, Аллергены, Название (каз), Состав (каз), КБЖУ (каз), Аллергены (каз)).
- Название в колонке «Товар» должно точно совпадать с названием на сайте.
- Непустая ячейка заменяет текст из `products.js`, пустая оставляет его.
- Новые товары лист не добавляет: нужна строка в «Ценах», запись в `products.js` и фото в `img/`.
- Номер листа записан в `config.js` (`productsGid`). Запасная копия — `products.csv`, её раз в сутки обновляет тот же GitHub Action, что и `prices.csv`.
- Если лист не открылся или в нём строка с неизвестным названием, самопроверка напишет об этом в «Логи проверки».
